## Remediation round 2 (2026-07-27) — P1/P2 sweep complete

All remaining P1s and P2s are closed.  Each fix carries a regression
test, and every test was checked against the PRE-FIX code rather than
against a single-line mutation (the layers are deliberately redundant,
so a one-line revert often leaves a sibling defense catching it).

**P1 — `jetpacs-sections--replay-key` still replayed the key.**  Defect
#1 of the rung, fixed in the palette and left standing two lines below
a gate this commit had already edited.  Worse here than in the palette:
the 23.2 gate resolved the binding with BUF current while
`execute-kbd-macro` re-resolved against the selected window's buffer —
so the command the denylist cleared and the command that ran were two
different lookups, and a destructive-magit entry could be refused on
inspection and reached in fact.  Now one lookup, run under the shims.

**P2 — a prompt that cannot reach the device is no longer raised.**
`jetpacs-emacs-ui` now hard-requires `jetpacs-dialog` (the rung's D2
story is false without it) and routes all three prompting flows through
`jetpacs-emacs-ui--with-prompting`, which checks the new public
`jetpacs-dialog-can-bridge-p` and refuses with a snackbar instead.  The
old behavior dropped `completing-read` into the REAL minibuffer — on a
daemon, a wedge nobody can answer, with the device already told
`accepted`.  The same wrapper gives every flow a `condition-case` that
reports the error SYMBOL only (23.3) rather than dying in a timer.

**P2 — M-x had no origin buffer.**  A `flow-continue` timer inherits
whatever buffer the pump was in, so `call-interactively` ran somewhere
arbitrary and the "follow it there" check compared against that
accident.  Origin is now the drilled buffer when one is on the stack
and a temp buffer on the hub — the refuter's correction, since a bare
`with-temp-buffer` would make `M-x occur`/`query-replace` useless.  The
follow now fires only when the command went somewhere ELSE and did not
error.

**P2 — buffers dying under a prompt.**  Both flows re-resolve the
buffer after the device round trip (which can take minutes) instead of
using an object captured before it; a killed buffer degrades to a
snackbar rather than signalling `Selecting deleted buffer`.

**P2 — SPEC 23.1 records outlived what they authorized.**  Whole-buffer
grants only ever accumulated.  The hub now forgets-then-re-exposes per
listed buffer (authorized == offered, the whole-buffer analogue of the
E4c span rule), and a `kill-buffer-hook` revokes a dying buffer's
grant — buffer names are REUSED (`*grep*`, `*shell*`), so a stale grant
would authorize a verb on a different buffer that took the name.

**P2 — the hub escaped the SPEC 4.5 byte budget.**  Rows built outside
the Tier-0 walk were invisible to the accounting, so a drilled screen
believed it owned the whole frame and the finished document blew
`max_frame_bytes` — which refuses the WHOLE SurfaceSpec, so an
over-long buffer list took the surface down instead of truncating
itself.  Rows are charged and truncate with a caption.

**P2 — `results.visit` landed nowhere.**  The default seam only armed
the region and re-pushed the current surface, so the slice appeared
only if a screen for the destination happened to already be on the
stack.  `jetpacs-emacs-ui-visit-region` arms, exposes and DEFERS a
drill to the destination.  Claimed with a free-or-ours guard, not a
nil-sentinel: this seam ships with a non-nil default, so an unguarded
claim would clobber a Tier-1's visitor by load order.

**P2 — `imenu-clear` cleared a region it did not own.**  It now clears
only when the armed region addresses our own top screen's buffer, and
answers `stale` otherwise, instead of silently discarding a grep/xref
slice another surface was presenting.

**A testing note.**  The hub-budget test initially passed with the
charging UNWIRED, because it drove the helper directly rather than
`--hub-screen`.  That is the vacuous-test shape this project keeps
finding: assert through the real entry point, or the wiring is untested.

per-map rather than aggregate (refuter downgraded to P3 —
