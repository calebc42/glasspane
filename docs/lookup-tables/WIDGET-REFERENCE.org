The Jetpacs widget system provides a comprehensive set of UI components designed to bridge three layers of the stack:
- *Elisp DSL*: The =jetpacs-*= functions developers call to construct user interfaces.
- *Wire format*: The JSON node types serialized and sent over the protocol.
- *Compose renderer*: The Material 3 (M3) composables the companion app renders natively.

There are 39 widget types across 5 families:
- *Core* (10): Fundamental building blocks and layout primitives.
- *Content* (8): Display-only components for information presentation.
- *Input* (10): Interactive controls for user data collection.
- *Layout* (8): Complex containers and scrollable regions.
- *Visualization* (3): Graphical representations like charts and calendars.

For each widget, this reference provides the Elisp function signature, Wire format string, backing M3 component(s), relevant specification section, detailed properties table, usage example, and the renderer source location.
